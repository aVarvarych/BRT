# BE-05 · HTTP-каркас, composition root, `/health`, помилки

**Епік:** 0 · Каркас · **Тип:** технічна · **Оцінка:** M · **Залежить від:** BE-04

## Навіщо
Тут закладається скелет, до якого підключатимуться всі ендпоінти, та єдиний підхід до помилок.

## Що зробити
- `src/index.ts` → `main/bootstrap.ts` → `main/compositionRoot.ts`, ланцюжок як у medbuy:
  - bootstrap читає конфіг, створює залежності, запускає сервер;
  - **graceful shutdown** на `SIGTERM` / `SIGINT`: перестати приймати запити, дочекатися поточних, закрити пул бази.
- `presentation/http/createApp.ts` — фабрика Express-застосунку. Вона приймає вже зібрані роутери, а не створює залежності сама.
- Middleware:
  - `express.json({ limit: '1mb' })`;
  - `requestId` (заголовок `X-Request-Id`, якщо прийшов, інакше генерується);
  - логування запитів (метод, шлях, статус, тривалість, requestId);
  - `notFound` → `404 { error: { code: "NOT_FOUND" } }`;
  - `errorHandler` (див. нижче).
- **Ієрархія помилок:**
  - `domain`: базовий `DomainError` з полем `code`. Конкретні помилки (`InvalidRouteName`, `TripAlreadyFinished`, …) з'являтимуться в наступних задачах.
  - `application`: `NotFoundError`, `ConflictError`.
  - `presentation`: `ValidationError` для невалідного тіла чи параметрів.
  - `errorHandler` переводить їх у `400` / `404` / `409` у форматі з README. Усе інше → `500` без деталей у відповіді, з повним стеком у лозі.
- `GET /health` без авторизації. Робить `SELECT 1` у базі й відповідає `200 { status: "ok", db: "ok" }` або `503`, якщо база недоступна.

## Критерії приймання
- [ ] `GET /health` → 200, коли база працює, і 503, коли її зупинено.
- [ ] Невідомий маршрут → 404 у форматі помилки.
- [ ] Integration-тест (supertest): тестовий роутер кидає `DomainError` → 400, `NotFoundError` → 404, `Error` → 500 без стеку в тілі відповіді.
- [ ] `Ctrl+C` завершує процес чисто, без «висячого» пулу.

## Підказки ментора
- Express 5 сам ловить відхилені проміси в async-обробниках. Обгортки `asyncHandler` не потрібні.
- Логер: `pino` легкий і пише структурований JSON. Його інтерфейс тримайте за портом `ILogger`, щоб `application` не залежав від `pino`.
